
# Reflection Questions

*1. How well does the code accomplish the goals you set out in terms of the test input set?*  
This code handles the processing, cleaning, and calculation of linguistic features fairly well, but does not accomplish the initial intent of accurately predicting coherence scores. The code effectively takes in the raw input data and produces cleaned narratives with non-alphanumeric characters removed, or output files that are segmented by word. It is slightly less successful at reformatting narratives to retain the intended punctuation and original utterance boundaries (discussed in the second question), but overall, it does manage to produce transcripts that are usable as input to natural language processing Python libraries. In addition, the functions written to derive linguistic features from the narratives are generally able to correctly calculate each feature from textual input, such as segmenting noun or verb phrases for syntactic complexity, calculating properties of individual words (e.g., frequency, semantic diversity), and quantifying relationships between words or utterances across various metrics (e.g., embeddings for semantic thematic similarity, shared nouns for co-referential cohesion). Thus, the code accomplishes the first goal of deriving linguistic features from the raw narrative data. However, although the classifier itself manages to assign coherence scores in a manner better than random chance, it does not have a reliable or high accuracy, precision, or recall for any score class. The performance of the model is somewhat dependent on the class of coherence score itself (e.g., recall and precision are particularly low for transcripts in the testing set with a gold-standard score of 1, but higher for those with a score of 3), which suggests some influence of the distribution of classes in the test and training sets. Moreover, results indicate that the chosen linguistic features may not be fully appropriate for the task, despite having theoretical support for their relation to coherence. Instead, it is likely that there is an aspect of narrative discourse used in human determinations of coherence that is not adequately captured by the derived input features. This limits the utility and extensibility of the code, allowing it to process and calculate linguistic features from the narrative transcripts as intended, but not to produce a corresponding classification model.

*2. How did you have to handle the trickier cases in your test set?*  
Because this test set used narrative discourse generated by large language models (LLMs), there were several narratives that were formatted unnaturally, especially with respect to punctuation; many within the HANNA dataset had special characters that were not recognized, or incorrect spacing between characters and punctuation. Although these characteristics might be relevant for humans in judging coherence of a narrative, it makes it more difficult to accurately utilize language processing libraries in Python for their intended purpose, including part-of-speech tagging and syntactic parsing. Consequently, these narratives had to be cleaned to align with conventional punctuation and utterance delineation conventions. The primary challenge in working with these narratives was writing code that would automatically replace certain characters or sequences of formatting errors through an expanding dictionary of Regex substitutions. This was not only complicated because of the large number of substitutions needed to address inconsistent formatting, but because it required writing the code in a way that would not inadvertently change the structure of correctly formatted narratives (e.g., turning plurals into possessives by removing or adding an apostrophe). To handle this, I went through example stories from each LLM used in either the HANNA and CoheSentia corpuses to determine whether the model was prone to a particular formatting style, then curated the Regex dictionary to account for any inconsistencies in the most general manner possible. I then tested the dictionary on a smaller sample of narratives containing one story from each LLM, which allowed me to identify any unintentional consequences of the updated Regex patterns. Once the narratives were cleaned to an acceptable degree (with some limitations, as discussed below), I found that I was able to use the feature extraction code with few issues. There were several narratives that were not at the length necessary to derive all features, especially local coherence using the Hoffman R code, or that otherwise returned unreliable feature scores due to grammatical abnormalities that led to a high rate of parsing or tagging errors; these were excluded from the classification model for ease of analysis and to retain formatting standardization across the remaining narratives.

*3. What are the limitations of your code? Can it handle any input it is given, or are there gaps for certain structures (e.g., input words, parts of the inflectional paradigm)? Consider input outside your initial test set.*  
The major limitation of my code is its inability to handle narratives that are formatted in a significantly different manner than either the HANNA or CoheSentia corpuses. Both datasets contain written narratives that are largely LLM generated, and therefore are not necessarily recorded in a way that mirrors the transcription of human language. Complex and natural speech patterns—repetitions or repairs, filler words, neologisms, or other components of spoken language—are not directly accounted for within the current code. Consequently, they will likely skew the results of the linguistic feature notebook, especially for features that rely on part-of-speech tagging, parsing, or content and information density measures; the derivation of these features using Python libraries such as SpaCy implicitly assumes cleaned and grammatically correct inputs containing words within the model vocabulary. A byproduct of this limitation is that this code is not particularly suitable for classifying coherence of human speech in clinical populations (e.g., persons with aphasia), in whom speech might be ungrammatical or otherwise impaired. In these populations, it is expected that the code will not produce a set of features that is an accurate reflection of the base language processes and thus will be highly inaccurate in assigning coherence scores. Additionally, the pipeline and classifier are only supported for English story-based narrative discourse, further restricting the extensibility of the code. Finally, the linguistic features themselves are limited in their accuracy and utility. The local coherence code, for example, requires windows of 20 words to form vector embeddings and will not output scores for shorter narratives. Similarly, the calculation of co-referential cohesion relies on the presence of identical nouns in two utterances; an alternative definition of cohesion, which considers noun or word stems rather than exact matches, has not been considered in this project but might be important in coherence judgments. Therefore, although the code itself utilizes language processing tools properly to derive linguistic features for coherence classification, the definitions and implementation of the features themselves is not comprehensive and may be contributing to the poor model performance.

*4. How does the research contribute to the larger task you set out to fulfill?*  
The broad question that this project aimed to address was whether it was possible to build a classifier that was able to predict local and global coherence scores for narrative discourse reflecting human judgments, and to identify the linguistic features that might be the most relevant in doing so. This project focused on global coherence (assessed across the entire narrative), and used a selected set of features thought to have some relation to coherence. This research provides the code necessary for deriving features that can be fairly easily adapted to local coherence or scores that extend beyond a 1–5 scale, and investigates a feature set that might be applicable to assessing other forms of coherence. In addition, the relative importance of each linguistic feature can be extracted from the current classifier model through different statistical methods. Thus, this project—although specific to story-based discourse and global coherence scores—acts as a framework for the associated broad question (predicting local and global coherence scores, and feature importance identification). However, considering the low accuracy of the classifier, it yields an additional perspective by implying that the standard linguistic features are not sufficient to appropriately predict coherence. This indirectly contributes to the larger task by challenging its feasibility and foundation, suggesting that it should be revisited by more clearly defining the relationship between coherence and discourse feature prior to the development of a classifier.

*5. What is a future direction work like this could take? How can this be expanded or complement other work, even outside the big-picture scope you initially envisioned?*  
Given the relatively poor performance of the random forest classifier, a pertinent extension of this project would be to identify an algorithm or linguistic feature set that would more accurately classify the coherence scores of narratives. A random forest classifier was chosen because they are fairly robust even when handling smaller datasets, and are designed to reduce overfitting. However, different algorithms (e.g., Multilayer Perceptron or k-nearest neighbors) may yield results that are more suitable for the given data, and testing the relative performance of each model in classifying coherence would be an interesting addition to the project. Furthermore, no feature or combination of features was particularly important in classifying coherence scores. This implies that other components of narrative discourse may be underlying human assessments of coherence that are not represented within the feature set. Therefore, in addition to creating a new feature set that provides better accuracy in classifying coherence, another future direction would explore why none of the included features were well-associated with coherence, considering that they cover a broad range of lexical, syntactic, and macrolinguistic factors. The current set also includes features that are thought to be automated metrics of coherence (specifically, local and first/second-order coherence), but the low model accuracy calls into question their efficacy. Identifying what these features are measuring in the narratives, and why they differ from human coherence scores, would be a useful extension. Finally, the input data was generated from LLMs rather than from human speech. Although the rationale behind using these corpuses was that they provided a large set of data with associated coherence scores and the factors that humans use to determine coherence should be consistent regardless of the source of the narrative, this assumption is worth examining, as differential judgment of known LLM-generated text may be skewing coherence scores. A possible future direction might be to investigate whether classification performance for the same set of features is significantly different for a coded set of human-produced narrative samples, and by extension, whether there exists biases in the treatment of LLM versus natural language.
